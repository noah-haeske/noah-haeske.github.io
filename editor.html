Editor Pick your repo folder to begin

Edit your site in place.

Click Choose site folder… and pick the noah-haeske.github.io folder. Chrome will ask permission to edit files in it — that permission lasts for this tab only.

How it works

  1. Pick a page from the dropdown. It renders exactly as it looks live.
  2. Click any text and type. Editable text glows on hover.
  3. Hit Save (or Ctrl+S). It writes straight to the real .html file.
  4. Open GitHub Desktop, commit, push.

What it will and won't do

It edits text: headings, paragraphs, course titles, link labels, table cells. It never touches your markup, so the layout can't break.

It won't add new sections, move things around, insert images, or change styling. That's still a job for me or a text editor.

Links inside the page are live — click one and the editor jumps to that page, so you can browse the site the way a visitor would. If you have unsaved edits it'll stop and ask first.

Chrome or Edge only. Firefox and Safari don't support writing to local files from a web page.
